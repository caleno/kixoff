# 🎮 KIXoff
A fast-paced, real-time multiplayer sports-arcade game built to run inside the Cloduron app platform.

## Core Features
- **Real-time 3v3 Multiplayer:** 60Hz server-authoritative game loop.
- **Cloduron Native:** Seamless SSO integration and in-app deployment.
- **Skill-Based Matchmaking:** Glicko-2 rating system.
- **Cross-Platform:** Responsive UI for desktop and mobile webviews.

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, WebGL Canvas
- **Backend:** Node.js, Express, Socket.io
- **Infrastructure:** Docker, Kubernetes, PostgreSQL, Redis
- **Security:** JWT Auth, Server-side validation, WAF
